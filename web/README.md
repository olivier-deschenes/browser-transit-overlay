# Support and privacy website

The French-language website for the Métro STM et REM extension uses TanStack Start, TanStack Router, React, and Tailwind CSS. It serves `/`, `/assistance`, and `/confidentialite` and prerenders the pages for deployment to Cloudflare Workers.

## Local development

Use Node.js 24 and npm. From this directory:

```sh
npm ci
npm run dev
```

Open `http://localhost:3000`. No environment variables, API keys, or Cloudflare login are required for local development or builds.

```sh
npm run lint
npm run typecheck
npm run check
npm run build
npm run preview
```

`npm run format` formats the website and applies lint fixes. The route tree is generated by TanStack; edit files in `src/routes/` instead of `src/routeTree.gen.ts`. The extension's behaviour tests are run from the repository root with `npm test`.

## Deploy your own copy

The committed `wrangler.jsonc` includes the original project's public domain, `metro.odeschenes.dev`. Before deploying a fork, change the Worker `name` and remove or replace `routes` with a domain you control. Update the support contact and project identity in the site content as appropriate.

After configuring your target and authenticating your own Cloudflare account:

```sh
npx wrangler login
npm run deploy
```

`deploy` builds the website and then deploys the generated Worker. For a local deployment validation, use `npm run build` followed by `npx wrangler deploy --dry-run`. The build creates the output and deployment configuration used by Wrangler.

No Cloudflare credentials are stored in the repository, and the CI workflow does not deploy. Keep any future local secrets in ignored `.dev.vars` or `.env` files, and use Cloudflare's secret management for production values.

See the [Cloudflare TanStack Start guide](https://developers.cloudflare.com/workers/framework-guides/web-apps/tanstack-start/) and [TanStack Start documentation](https://tanstack.com/start/latest/docs/framework/react/overview) for the framework's deployment configuration.
